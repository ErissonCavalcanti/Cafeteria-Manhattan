📌 Sobre

Landing page para uma cafeteria fictícia, construída sem frameworks nem bibliotecas. O foco do projeto foi praticar layout responsivo, manipulação do DOM e animações baseadas em scroll.

<br>
✨ Funcionalidades
	Funcionalidade	Descrição
📱	Responsivo	Adaptado para desktop, tablet e mobile
🍔	Menu mobile	Menu hamburger com abertura e fechamento por toggle
🎞️	Animação de scroll	Zoom no fundo do banner e fade do título e do botão ao rolar
↩️	Estado reversível	Os elementos voltam ao estado original ao retornar ao topo
<br>
🚀 Como rodar localmente

Não é preciso instalar nada:

bash
git clone https://github.com/ErissonCavalcanti/Cafeteria-Manhattan.git
cd Cafeteria-Manhattan

Depois, abra o index.html no navegador ou use a extensão Live Server do VS Code.
